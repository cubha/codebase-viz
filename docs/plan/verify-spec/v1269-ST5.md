### VERIFY-SPEC — SubTask ST5 (Tab2 같은 path 정적 라우트 소실)

- 기준선: 재실측 손실 지점 ③ `pathToDisplayRoute` 경로 dedup.
- 변경 파일: `packages/renderer/src/mermaid-renderer.ts` (+test)
- 관찰 가능한 계약: FE Tab2에서 정적 파서 라우트는 같은 path여도 전부 표시. `provenance.adapter`가 `llm-`인 라우트만 같은 path의
  정적 라우트(없으면 먼저 온 LLM 라우트)로 흡수, renders 엣지는 흡수 대상으로 재매핑(기존 동작).
- 구현 결정: 원래 주석 의도("prefer verified over inferred (LLM duplicates)")를 confidence가 아니라 adapter로 판별 — Angular 정적
  라우트도 컴포넌트 매핑 시 confidence가 `inferred`라 confidence로는 LLM 중복과 구분 불가.
- 인접 경계: BE는 이 함수 전에 `buildBeArchitectureDiagram`으로 분기(무영향). `text-size-baseline.json`의 BE fixture 수치가 늘어난
  것은 그 테스트가 metadata에 adapterCategory를 안 넣어 BE를 FE 경로로 렌더하기 때문(하네스 한정 — 같은 path의 GET/POST가 이제 각자 표시).
- 미확인 사항: Vue SPA·Nuxt 등에서 정적 파서가 같은 path를 중복 emit하는 경우가 있으면 Tab2 박스가 늘 수 있음 — 스냅샷 13 fixture에선 변화 없음.

### VERIFY-SPEC — SubTask ST3 (Drizzle 센티넬)

- 기준선 요구사항: Drizzle 클래스(변수)명 센티넬.
- 변경 파일: `packages/core/src/db/drizzle-parser.ts` (+test)
- 관찰 가능한 계약: `export const usersTable = pgTable('users', …)` → `orm-class:usersTable`(배열 뒤).
- 구현 결정: Drizzle엔 클래스가 없어 코드가 참조하는 식별자인 **변수명**을 센티넬로 쓴다. 배지 표시는
  `isInformativeOrmClass`가 판정(`usersTable` vs `users`는 정규화 후 달라 배지가 **뜬다** — 의도 여부는 critic 판단 요망).
- 인접 경계: 구조분해 선언 등 비정형 선언은 `TABLE_FUNCS` 호출 판정에서 이미 걸러진다.
- 미확인 사항: Drizzle 컬럼은 여전히 TS 키(`authorId`)를 컬럼명으로 쓴다 — DB 실제 이름(`'author_id'`)과 다른 같은
  결함 클래스지만 이번 범위에 넣지 않았다(PLAN 미포함, 잔여로 보고). `usersTable ⌗` 배지가 노이즈인지 미판정.
